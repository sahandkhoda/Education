# 📚 Courses

This folder contains the courses I have completed as part of my studies at **BSc Medical Engineering**.

Each course has its own directory with course-specific material, including assignments, laboratory work, programming projects, reports, presentations, notes, and documentation. Most folders also include a dedicated `README.md` summarizing the course content, learning outcomes, and key technical skills developed.

## 🎯 What You'll Find

- Programming assignments and projects
- Laboratory exercises
- Technical reports
- Course notes
- Presentations
- Documentation
- Course-specific README files

## 💡 Purpose

The goal of this repository is to document my academic journey and demonstrate the technical knowledge, engineering skills, and practical experience gained throughout my studies. Together, these courses provide a foundation in software development, artificial intelligence, data analysis, mathematics, medical engineering, and healthcare technology.

Each course reflects a different aspect of engineering and problem-solving, showcasing both theoretical understanding and hands-on implementation.
